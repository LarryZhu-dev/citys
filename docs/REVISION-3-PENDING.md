## 已实现的程序修正

- 施工图片只整件显示或隐藏，移除逐构件 UV 裁切。工序中的施工进度只驱动工人动作，不再用于绘出半个构件。
- 保留既有经济总工期，根据构件用途和体量分配安装时间。分层柱梁先完成下层承重；升级保留未变构件，需要替换的旧结构从上向下整件拆除后再安装。
- 工人使用同一份确定性施工动作表。构件目标失效或完成后停止敲击，连续返回材料点；拆除任务返程携带旧料。
- “减少动态效果”不再暂停人物。人物使用真实经过时间而不是每帧最多 0.1 秒；方向、行走、负重、装卸、敲击、爬梯、马匹步态及车轮有独立动画接口。**新接口不等于新动作图已完成。**
- 未选中的施工建筑也显示剩余时间、升级、暂停或断路状态。时间来自模拟快照，不建立另一个倒计时。标签避让 HUD 和建筑，远景聚合并限制数量，完工立即撤销，不拦截地图输入。
