## 本作数值设计

除粮仓/货栈的 2 分钟历史参考，以下均为本作平衡方案，不冒充原作复刻表。保留旧档其他文明；新体验可只开放华夏。

- 经营模式：一现实秒等于一施工秒。4 倍、60 倍不会加快经营模式。游戏桥的暂停与在线事务使用 `suspended:true`，会消耗时间水位、暂停一切且不追补；关闭页面后重新载入按离线规则结算。
- 自由营造：可以明确启用 4 倍或 60 倍。0 倍会消耗时间水位而不经营。关闭页面后的离线经过时间不乘此前倍率。
- 统一每 60 秒结算经济。原抽象回合改为一分钟的经济基准：基础粮食消耗 0.035/人/分、已满足的多样食物 0.006/人/分、工艺用品 0.002/人/分；移民、降级宽限、声望、火灾也沿同一尺度。
- 住宅税收每 30 分钟一次。升级工程期间保留居民，按原等级正常收税；升级期间不额外移民。满足下一等级条件且入住率达到 90% 持续 10 分钟后获得升级资格；玩家手动点击并支付材料才开工。需求缺失持续 45 分钟才降级。
- 基础住宅 5 分 6 秒、水井 3 分 24 秒、粮田 12 分 45 秒、伐木场 12 分 45 秒、仓储 2 分钟（华夏）。道路即时铺设。
- 砖窑 34 分钟、陶器坊 51 分钟、中央集市 51 分钟、港口 2 小时 33 分钟、九重宝塔 5 小时 6 分钟、观象台 10 小时 12 分钟；奇观 30 小时 36 分钟（华夏）。
- 华夏普通住宅各级升级施工约 4分15秒、8分30秒、17分、34分、51分、1时42分、3时24分、6时48分、10时12分。基础表还保留文明建设系数兼容旧档。
- 生产批次：伐木/石矿/粘土 5 分钟，鱼/铜/砖/磨坊 10 分钟，陶器 15 分钟，蔬菜/织布 20 分钟，粮食/果园/牧场/酒坊 30 分钟。产量与原料 = 每分钟基准 × 批次分钟数 × 对应文明/位置加成；原料不乘产量加成。
- 批次启动立即扣除整批原料，多个工坊不能重复消费同一份库存。批次中的原料不重复扣费。断路、缺工、受损、仓储不足均暂停，已投入进度保留；无原料不启动下一批。每分钟调度，完工生产建筑最迟在下一分钟开始批次。
- 完成的批次通过真实道路运输到适合的粮仓/仓库，尚无库房时使用城镇货栈。装货 15 秒、每道路格 3 秒、卸货 10 秒；到库前不加入可用库存。运输中断保留货物，恢复道路后重寻路。商铺补货在派车时预留库存，取水人到井后带水回家。
- 本作便利规则：离线自动经营最多 8 小时；此后人口、消费、税收、生产冻结，已经排队且连路的施工最多推进 72 小时，不启动额外住宅升级。建设完成可触发章节奖励/胜利。未用时间不留到下一次登录再补发。
- 火灾每经营小时检查，开局前 5 小时保护，风险仅针对缺少消防覆盖的运营生产建筑；停工修复 18 分钟，有修缮覆盖加快。

## JS / Godot Bridge 接口

`newGame({civilization,cityName,seed,mode,nowMs?})`、`doBuild(type,x,y)`、`serializeState()` 保持。`simulate()` 现在只读取现实钟，不再每调用一次就凭空经营一分钟。

```js
advanceClock(Date.now(), { speed: 1, suspended: false });
advanceClock(Date.now(), { offline: true }); // 加载补算；不乘自由营造倍率
step(60);                  // 明确推进 60 逻辑秒，测试/内部适配用
stepSimulation(60);        // step 的别名
hydrateState(data);         // 新格式补算离线，旧格式无历史收益
hydrateState(data, { nowMs: Date.now(), applyOffline: false }); // 只读参观/事务恢复
productionProgress(b);    // {elapsed,duration,progress}；读取真实生产批次
constructionDuration(type, fromLevel = 0, civilization = S.civilization);
```

**时间字段均为秒**：`b.construction.{total,remaining,fromLevel?,toLevel?}`、`b.damage`、`b.taxTimer`、`b.upTimer`、`b.missTicks`。

新增持久字段：

```js
S.clock = { version:1, lastWallMs, elapsedSeconds, accumulatorSeconds }; // accumulator ∈ [0,60)
b.production = { elapsed, duration, multiplier }; // 可选；投入原料已经从 goods 扣除
b.productionTicks; // 收获完成的批次数，仅用于既有动画兼容
```

`S.tick` 为已结算经济分钟数，不含离线超过 8 小时后的施工时间。`S.clock.elapsedSeconds` 为实际推进的逻辑时间。`S.lastDelta` 保留全资源/金币/人口净变化，`S.lastDeltaSeconds` 给出该批净变化对应的经济秒数；不足一分钟时保留最近完整结算。`S.offlineSummary` 与 `b.idleReason` 是派生 UI 信息，无需服务器持久化。

服务器校验应允许最多 259200 秒施工；计时器上限：税 1800、升级观察 600、缺需 2700、受损 3600；production.duration 依建筑的 cycleSeconds，elapsed ∈ [0,duration]，multiplier 0.1–4。`lastWallMs` 为毫秒时间戳，不能按普通资源 1e9 上限截断。

### 旧档迁移

缺少 `clock.version===1` 的旧存档只迁移格式，不根据 savedAt 回溯奖励。保留土地、建筑身份、等级、人口、资源、章节及随机数状态；旧施工以 remaining/total 比例映射到新总时长，旧住宅税/升级/缺需计时乘 60。旧已完成城市不重置。新生产批次保存投入状态与进度，不会读档重复扣原料。

单调 `lastWallMs` 防止重复调用/时钟倒退重复发放，离线结算后水位移动到当前时刻，超上限时间被消费。客户端本地钟不是反作弊权威时间；服务器若需要强反作弊，应另设服务器时间戳与权威经营服务。

## 回归与性能

`tests/clock.test.cjs` 覆盖现实钟、秒级施工、长批次、停工、离线与逐帧一致、8/72 小时上限、重复/逆向时钟、在线事务暂停、自由倍率、旧档迁移、只读访问与深快照。原始合法初始预算通关测试仍保留，`tests/simulation.test.cjs` 改用显式 step(60)，不通过系统真实等待。

压力验收脚本 `work/benchmark-time.cjs` 使用 renderer 同类非法遍历压力城，437 住宅 / 441 非道路建筑，不作为玩家城市。当前记录在 `work/time-benchmark.json`：经济分钟 step 均值约 3.8 ms、p95 5.0 ms；8 小时离线 480 步约 1.19 秒（Node VM，本机）。旧浏览器同类每步约 342 ms；环境不同，不能将两者当严格同机性能比例。

道路连通、按服务类型索引、覆盖与住宅环境缓存按布局/完工/工作人员/受损状态失效。不是按每帧重新做全图路径与服务扫描。离线循环按分钟执行，不循环 28800 次秒数。
