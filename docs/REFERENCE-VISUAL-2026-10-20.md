## 画面为什么比当前版本丰富

1. **先看得到建筑类别，再看得到装饰。** 圆殿、塔、合院、街屋、长厅、城墙具有不同的大轮廓。去掉颜色以后仍有区别。
2. **屋顶具有完整层次。** 瓦垄是有方向的密集细线；屋脊有较浅的窄高光，檐底有较厚的暗带，角檐和侧檐形成清楚的外轮廓。细节不是均匀撒在表面的噪点。
3. **立面不是平板贴门窗。** 红木构、暖白墙、门窗暗洞和浅色框线形成前后层次；门窗、柱梁、檐口之间留有可理解的结构关系。
4. **同一建筑有大小构件对比。** 大而连续的屋面和墙面搭配窄脊、细柱、短栏板、台阶及附件，避免每个部件都被做成同样大小的积木。
5. **庭院与街面参与轮廓。** 院墙、门楼、石岸、台阶、铺地和少量植物使建筑与道路相接。密度不是简单把主屋挤到地块边缘；需要用这些部件完成地块边界。
6. **色彩集中，明暗有方向。** 石材偏米灰，墙面偏暖白，木构深红或棕色，瓦有冷灰、蓝灰、绿和金黄。局部阴影较深，但边缘和受光面仍清楚。不能用全图灰雾代替这种关系。

投影从可见道路和建筑轴线看接近本作使用的 2:1 斜俯视，但尚未对附件原始像素作精确测量。此处不给出假精确的相机角度、瓦片数量、占地百分比或人物身高。

## 与当前配方的明确差距

已只读检查 `godot/world/building_parts.gd`：

- `_roof` 固定为两面直坡、矩形瓦排和单一直脊。它可以表达普通双坡屋面，不能覆盖图中的圆形重檐、多边密檐和带转角的四向屋顶。
- `_room` 自动走同一套 `_frame` 与 `_roof`。不同建筑的墙高和矩形大小虽然不同，结构语汇仍相同。
- `_wall_line` 主要根据墙材在两种门、两种窗之间选择。山墙、街屋入口、敞开店面和仪式性建筑立面缺少专门件。
- `_pagoda` 的每层仍调用矩形 `_room`，所以不会自然得到参考图中多边塔身与连续环绕密檐的轮廓。
- `_palace` 的主殿、上殿、侧廊和门楼仍复用相同通用房间；需要独立的屋檐组合、门楼立面和台基构件。
- `_shop` 中粮、菜、果、鱼、肉店共用同一主屋、棚、柜台，只替换小货物。这是代码中可以确认的重复原因；本图不足以给出这五种店的原版准确样式，应原创设计功能不同的前脸和陈列构件。
- `_tree` 用同一种树干和 `fruit_branch` 拼出庭院树、果树和灌木；截图里的垂柳、挺立常绿树、粉花树及低矮灌木明显不同，植物不应再只换尺度。

## 首批重制与拼装的验收重点

先用统一的石基、立柱、梁、墙、门窗、瓦排、直檐、角檐、屋脊组成三种不同轮廓：窄街屋、围合小院、带外挑檐角的厅堂。以拼装结果而非单张构件大图验收以下事项：

1. 同一道路轴线下，墙基、门槛、柱网与屋脊方向一致；不靠旋转整栋图片伪装方向。
2. 将颜色暂时看成同色后，三种建筑仍能通过轮廓和入口结构区分。
3. 小缩放时屋脊、檐下暗带与门洞仍清楚；大缩放时能看到瓦垄和木石纹理，避免微纹理变成噪声。
4. 构件接缝不露空、阴影不重叠发黑；所有构件在安装时整件出现。
5. 未安装的屋面不靠完成态整栋贴图补上；工人目标、柱梁支承层级和上层遮挡沿用既有真实施工合同。
6. 灯窗、门洞、檐底和地面投影分层保留，方便后续材质夜色与局部灯光；本白昼图不能作为夜景通过证据。

人物与马车需要另做原创细节和动作设计。本图只能提供“大致有人物在街上”的存在证据，不能提供可分离的人体部件、马腿姿态、车轮结构或动作周期。
