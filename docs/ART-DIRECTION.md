# 美术方向与制作验收

审阅日期：2026-10-20。目标是具有生活密度、清晰建筑层级和统一材质语言的原创华夏城建游戏；当前画面仍有明显差距，不宣称达到或超越商业原作质量。

## 参考与证据范围

原版参考来自 [OurPlay 华夏截图](https://www.ourplay.net/rank/detail/118382) 与 [Steam《模拟帝国》城市及夜景](https://steamcommunity.com/app/1041710)。主代理实际查看原版图后记录：华夏街坊紧凑，多种瓦顶、屋脊与楼阁形成高度层次；石街边有植被与经营物件；夜景以紫蓝环境衬托明亮金黄窗火。此处采用主代理的直接观察，本次文档作者未取得这些原版图片的本地副本，不能据此认定原作的精确尺寸、灯光参数或完整动画规则。

以下 v2 差距记录来自旧版 `work/perf-investigation/v2/godot-day.png`、`godot-night.png`，不能作为新构件版本的验收结论。新版本逐项检查住宅施工、拆顶与分解图，再检查全类别和实际城市日夜画面。参考图不属于本项目资产，也未被裁切用于游戏。运行资源为项目原创生成图及其机械裁切、组件装配；原图、提示词与来源保存在 `godot/art/*/sources/`。

## 本轮独立构件图审

新建筑图库包含 72 张原创小构件，无缩放打包为一张 4096×4096 的无损共享图库，便于引擎合批。工人另有 56 张四向动作帧。全部 42 类华夏建筑、10 级普通住宅、6 级高级住宅使用这些新图片；原有整栋、房屋翼、完整屋顶及帐篷图片均已删除。

实际 Godot 画面检查覆盖全类别、两类住宅全部等级的日夜对照、三级住宅 16 个施工时点、拆顶/分解图、相邻高低建筑，以及工人搬料、安装、爬梯和完工离场。图审中修正了地基穿顶、屋面缝隙、烟道层高、帐篷山面、货物穿棚、上层入口、墙窗遮挡及梯顶遮挡。井圈与窑体使用独立生成的四向弧段，磨盘和浑仪分别使用新石磨盘与青铜刻度环。

夜色逐材质染成冷月光，纸窗与格窗采用不同的发光区域；格条和窗框不跟随窗洞发亮。工地灯笼、光晕与地面暖色光池跟随实际灯位，施工结束后随临时设施撤走。实际浏览器性能及操作结果记录在 [VALIDATION.md](../VALIDATION.md)。

当前仍有构件复用、同类店铺轮廓相近、远景物件辨识较弱等美术限制；人物是四向图片动画，不是完整骨骼动画。这轮证明了独立构件装配与动作流程，不能据此宣称达到原作的建筑种类、美术丰富度或商业完成度。

## 旧 v2 观察：已改善的具体表现

- **结构细节能在地图中读出。** 灰瓦屋面、檐口、红木梁柱、白墙与石阶已有材质区别，住宅、楼阁、院墙和仓储能形成不同轮廓，优于早期粗几何拼装。
- **界面有一致的材料。** 顶栏与底部操作栏使用胡桃木、青铜和金色原画；城市名牌用纸质卡片。资源图标与按钮材质接近，已摆脱早期整片纯色面板的观感。
- **昼夜保留场景可读性。** v2 夜图的地面和植被明显变冷变暗，屋顶轮廓与 HUD 仍可辨认。截图可证明环境调色成立，不能单凭这一对静帧证明灯火动画、施工动画或行走连续性。

## 当前生产规范

1. **先锁定尺度样板。** 用一名成人、一扇门、一格道路与一栋两至三开间街屋共同校准。世界沿用 2:1 地轴；每个构件记录占地、基脚锚点、视觉高度、前后遮挡片，禁止按透明图片外接框统一宽度后直接拼装。
2. **只生成可独立安装的小构件。** 基础石块、柱、梁、墙段、门、窗、斗拱、椽条、短瓦排、檐条、脊段分别绘制，禁止完整建筑、房屋翼、完整屋顶和整顶帐篷。旧建筑原画全部弃用并删除。图片可以映射到二维投影平面，不能改用实体几何建筑。弧形井沿和炉壁使用同一相机下真实对应的方向片，不能把一个视角的图片任意旋转后当成四向。每片保留源图与裁切区域，拼接处先做实际画面检查。
3. **施工安装实际构件。** 地基、骨架、墙体、椽条、瓦排与设备有独立顺序；完工保留这些图片和节点，不换成成品贴图。升级保留未变化部分并拆换变化构件。工人沿真实安装点搬料、上架、安装和离场；人物至少四朝向和实际步态帧，维持一致身高、落脚点和持物位置。暂停和断路冻结动作，不能凭单帧精度认定动画完成。
4. **夜景单独交付发光信息。** 提供窗洞、灯笼、炉口的发光蒙版和局部灯位；蒙版贴合真实结构，避免悬空黄圈、整屋发亮和大面积雾光。用最新运行版本验收日夜配对效果。
5. **以实际显示尺寸验收。** 同一街段输出远、中、近三档昼夜画面，再检查桌面与手机。轮廓、门洞与经营用途先清楚，细瓦和纤维纹理随后；HUD 九切角保持比例，文字区域避免强纹理。每批保留原图、提示词、可复现排图脚本及失败案例，不用原图像素数代替最终画质判断。
