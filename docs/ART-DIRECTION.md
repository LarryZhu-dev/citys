# 美术方向与制作验收

审阅日期：2026-10-20。目标是具有生活密度、清晰建筑层级和统一材质语言的原创华夏城建游戏；当前画面仍有明显差距，不宣称达到或超越商业原作质量。

## 参考与证据范围

原版参考来自 [OurPlay 华夏截图](https://www.ourplay.net/rank/detail/118382) 与 [Steam《模拟帝国》城市及夜景](https://steamcommunity.com/app/1041710)。主代理实际查看原版图后记录：华夏街坊紧凑，多种瓦顶、屋脊与楼阁形成高度层次；石街边有植被与经营物件；夜景以紫蓝环境衬托明亮金黄窗火。此处采用主代理的直接观察，本次文档作者未取得这些原版图片的本地副本，不能据此认定原作的精确尺寸、灯光参数或完整动画规则。

本项目的直接审图对象为 `work/perf-investigation/v2/godot-day.png`、`godot-night.png`，均为 1440×900 整城截图；并与早期 `work/godot-first.png` 对照。参考图不属于本项目资产，也未被裁切用于游戏。运行资源为项目原创生成图及其机械裁切、组件装配；原图、提示词与来源保存在 `godot/art/*/sources/`。

## 已改善的具体表现

- **结构细节能在地图中读出。** 灰瓦屋面、檐口、红木梁柱、白墙与石阶已有材质区别，住宅、楼阁、院墙和仓储能形成不同轮廓，优于早期粗几何拼装。
- **界面有一致的材料。** 顶栏与底部操作栏使用胡桃木、青铜和金色原画；城市名牌用纸质卡片。资源图标与按钮材质接近，已摆脱早期整片纯色面板的观感。
- **昼夜保留场景可读性。** v2 夜图的地面和植被明显变冷变暗，屋顶轮廓与 HUD 仍可辨认。截图可证明环境调色成立，不能单凭这一对静帧证明灯火动画、施工动画或行走连续性。

## 仍需解决的差距

| 部位 | v2 截图中的具体问题 | 下一步优先事项 |
| --- | --- | --- |
| 街坊与体量 | 上半幅大片均质草地，宽直道路直接接建筑；部分小亭、院墙占地很大而主体很小。 | 先制作一组住宅—商铺—作坊连续街段，校准人物、门洞、道路与院落比例；不把整城样板的空地直接当成引擎能力不足。 |
| 建筑辨识 | 右上两排建筑、中央街屋反复使用相近屋顶和立面；多种用途仅靠组合数量区别。 | 每个建筑类别至少增加一个用途明确的轮廓特征，如卸货口、灶房、货棚、招幌或灌溉构筑物，避免只换颜色。 |
| 地面与接地 | 草地呈连续模糊斑块，道路边缘过直；建筑基脚与地面之间缺少土色、磨损和接触阴影过渡。 | 制作路肩、夯土院地、石板入口和接地阴影；细节跟随入口与使用路径，控制重复频率。 |
| 生活密度 | 大量树木聚在左下，街边货物、绿篱、摊位与小型设施较少；细瓦和树叶有时抢过建筑主轮廓。 | 补齐可控密度的经营物件与街边植物，降低远景高频纹理对比，保留建筑整体明暗。 |
| 夜间层次 | v2 图主要呈现环境变暗，暖窗和局部地面受光不突出。 | 后续已修改加色柔光，须用最新版同机位截图复查；验收应看到独立暖窗、灯笼与地面小光池，同时保留冷色阴影。 |

## 下一批生产规范

1. **先锁定尺度样板。** 用一名成人、一扇门、一格道路与一栋两至三开间街屋共同校准。世界沿用 2:1 地轴；每个构件记录占地、基脚锚点、视觉高度、前后遮挡片，禁止按透明图片外接框统一宽度后直接拼装。
2. **按中尺度结构制作。** 分别生成完整瓦顶、带门窗的屋身翼、院门、店面、作坊和院墙转角。统一左上光源、瓦片尺寸和墙柱比例；同类建筑准备不同屋面与经营细节，先在真实地图中审核，再扩充数量。
3. **阶段与动作共享坐标。** 地基、骨架、墙体、屋面、完工细节使用同一画布和底锚；升级保留旧建筑及拆换关系。人物至少四朝向，步态帧维持一致身高和落脚点，另交施工、搬运、采集动作；不能凭单帧精度认定动画完成。
4. **夜景单独交付发光信息。** 提供窗洞、灯笼、炉口的发光蒙版和局部灯位；蒙版贴合真实结构，避免悬空黄圈、整屋发亮和大面积雾光。用最新运行版本验收日夜配对效果。
5. **以实际显示尺寸验收。** 同一街段输出远、中、近三档昼夜画面，再检查桌面与手机。轮廓、门洞与经营用途先清楚，细瓦和纤维纹理随后；HUD 九切角保持比例，文字区域避免强纹理。每批保留原图、提示词、可复现排图脚本及失败案例，不用原图像素数代替最终画质判断。
