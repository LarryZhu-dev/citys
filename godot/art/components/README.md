# 华夏构件图像 v4

本轮图像依据用户直接上传的《模拟帝国》华夏城市画面分析后重新生成。
它们是原创重制的图像构件，不是从原游戏文件中取得的资产。实际参考分析见
[REFERENCE-VISUAL-2026-10-20.md](../../../docs/REFERENCE-VISUAL-2026-10-20.md)。

建筑在施工中和完工后都使用同一套独立构件节点。墙段、柱梁、门窗、短瓦排、
檐段、脊段、设备和树枝分别安装；没有完工时切换整栋或整屋顶图片的路径。
曲檐和多边屋面通过独立图片的二维安装坐标实现。

`sources/v4/` 保留原始生图、提示记录、逐件源像素选择、投影校准与源文件摘要。
旧建筑构件源图和旧打包路径已移除，旧像素摘要仅用于拒绝复用。精确来源记录
区分原始提示词和未保存逐字提示词时的规格摘要。

```sh
python godot/art/components/sources/v4/build.py
python godot/art/components/sources/v4/validate.py
```

打包器仅输出到 `work/art-v4/packed`，不自动覆盖游戏资源。它保留原生像素，
使用单个不超过 4096×4096 的共享图集，并检查透明边距、重复素材、旧像素
复用和源文件对应关系。`complete` 表示素材键齐全；
`ready_for_activation` 还要求实际拼装画面审查，两者不能混为一谈。

修改源图、裁切或配方后，必须重新导入 Godot 并查看实际渲染结果。
`tests/godot/art-catalog-visual.gd` 生成使用真实渲染器的日夜及施工画册；
画册是审查场景，不是玩家存档。程序测试不代替美术质量判断。
