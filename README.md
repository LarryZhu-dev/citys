# 万城纪 · Empires at Dawn

原创美术的中文等距城建游戏。2.0 使用 **Godot 4.6.3 Web** 渲染世界、组件建筑、人物与 HUD，沿用 JavaScript 经济和 Node.js 在线服务。新建城市暂只开放华夏；其他地区显示「暂未开放」。

研究参考《模拟帝国》的城市层次与经营规则，没有提取原作美术。参考、具体实现和已知差距见 [Godot 实现](docs/GODOT.md)、[美术方向](docs/ART-DIRECTION.md) 与 [数值说明](docs/TIMING.md)。不以换引擎或自动测试通过代替商业品质验收。

## 运行

```sh
npm ci
npm start
```

需要 Node.js 22.9 或以上，打开 `http://localhost:3000`。仓库包含 Godot Web 导出产物，不必安装编辑器即可游玩；浏览器需要 WebAssembly 和 WebGL 2。首次载入需下载引擎与资源包。

本地服务器同时提供真实账号、云存、参观、排行和交易，开发数据保存在 `work/local-online.json`。Vercel 生产环境使用 PostgreSQL，见 [DEPLOYMENT.md](DEPLOYMENT.md)。请通过 HTTP 访问，不能直接双击 HTML。

修改 GDScript 或 Godot 美术后需重新导出：

```sh
npm run engine:export
npm run build
```

引擎与官方模板版本固定为 4.6.3，安装位置见 [docs/GODOT.md](docs/GODOT.md)。构建校验导出物的 SHA-256，排除旧 Canvas 与未使用的旧精灵。编辑器单独运行场景不会连接浏览器中的经济，当前交付目标是 Web。

## 内容与操作

- 64×64 种子地图，噪声生成草土、河湖、林地和不规则矿脉。
- 华夏 42 类非道路建筑、道路、10 级普通住宅、6 级高级住宅；六章目标与终极奇观。
- 16 个新生成的中尺度建筑结构件按配方组合，分阶段建造、增层换顶；地面锚点排序，生产动画跟随真实批次。
- 分材质月光与暖灯加色柔光，四方向工匠沿可达道路往返；48 个原创资源/操作图标和四套九切 HUD 面板。
- 建设持续分钟到小时，华夏奇观约 30 小时；生产每批 5–30 分钟。自由营造提供 1/4/60 倍，征程按真实时间运行。
- 离线自动经营最多结算 8 小时，已有施工最多推进 72 小时；重复读档不会重复发放时间收益。
- 自动存档、三个手动槽、JSON 导入导出、切城备份和旧档迁移。旧文明数据保留，新美术和首发平衡专注华夏。
- 真实账号、版本化云存、只读城市参观、繁荣榜、物资托管与原子交易，另有单机商队。

底部「营造」选建筑，再点地图放置；「修路」可拖动铺设。点击建筑查看需求、迁移或拆除。空白处拖动平移，滚轮或双指捏合缩放。顶部查看库存与城志；「视野」切换昼夜、覆盖层和舆图；「城务」包含档案、设置和帮助。手机横竖屏分别排布，常驻 HUD 留出主要地图空间。

起步先修水井、增加住宅，再安排粮食和木材。服务和生产设施需要道路与工人；同类早期商铺隔路成对，中央集市可整合配送。住宅满足需求并稳定居住后自动升级，不以点击立即升级跳过经营。

暂停和在线事务窗口会冻结当前经济并更新时钟水位；关闭页面后的离线规则另行结算。在线市场属于休闲社区：客户端负责模拟，服务端防止重复成交和版本覆盖，但排行榜不保证竞技公平。本次联网范围不含实时共同建城或战争。

## 验证

```sh
npm test
npm run build
npm run test:godot
npm run test:browser
```

浏览器验收默认使用系统 Chromium，可设置 `CHROMIUM_PATH`；测试使用临时账号数据库。`test:godot`（亦即 `test:visual`）检查真正的 Godot Web 场景、桌面/手机横竖屏、触摸建造、拖动、捏合和存档。`test:browser` 检查两账号的云存、参观、排行、交易与丢响应恢复。

自然预算的完整通关路线约 **58 小时 28 分钟模拟时间**，人口 616；没有添加资源跳过经济。这证明目标可达，不代表玩家普遍完成时长。可导入 [范例城市](examples/completed-city.json) 检查布局与建筑，范例不是在线玩家。

具体测试结果、软件 GPU 性能及尚未完成的生产/真机验收见 [VALIDATION.md](VALIDATION.md)。原始生图、提示词及处理工具保存在 `godot/art/*/sources/`，不导入运行包。旧 Canvas 实现与旧素材保留在源码中供追溯，但不再由产品页面加载。
