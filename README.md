# 万城纪 · Empires at Dawn

一款原创美术的中文等距城建游戏。从第一口水井开始，经营住宅需求、生产链与服务覆盖，发展五种古代文明，完成六章目标并建设奇观。

本项目在原 `citys` 单机骨架上继续开发，研究参考《模拟帝国》，没有提取或使用原作游戏资产。参考来源与规则差异见 [RESEARCH.md](RESEARCH.md)。

## 开始游玩

需要 Node.js 22.9 或更新版本。

```bash
npm ci
npm start
```

打开 `http://localhost:3000`。选择文明、城市名称及世界种子，再选择「文明征程」或「自由营造」。浏览器内自动存档可离线保留；使用 HTTP 服务器打开游戏，不要直接双击 `index.html`。

本地服务器同时运行真实账号、云存、参观、排行与交易接口，开发数据保存在 `work/local-online.json`。它用于本地测试；发布到 Vercel 时必须配置 PostgreSQL，部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 当前内容

- 64×64 种子地图、河流湖泊、林地、矿脉、跨水道路和小地图导航。
- 五文明及对应经济差异：华夏建设与工艺、埃及采矿与河谷农业、希腊税收与移民、波斯贸易与仓储、阿兹特克农业与美化；各有专属建筑和奇观。
- 47 种建筑定义，包含文明专属建筑；每个文明可用其中 43 种。10 级普通住宅、6 级高级住宅及完整商品与公共服务需求。
- 建造与升级工期、道路与工人要求、原料消耗、真实净产量、污染与美化、消防和修缮。
- 六章递进目标；奇观真正完工后达成文明胜利，城市仍可继续经营。
- 保留居民、等级与建设进度的建筑迁移；迁移收取原建材成本的 15%，向上取整。
- 地基及覆盖层、昼夜照明、建筑运行和施工动效、暂停与低动态模式。
- 自动保存、三个手动槽、JSON 导入导出、切城备份与旧 20×20 存档迁移。
- 真实账号、版本化云存、公开城市只读参观、休闲繁荣榜、物资托管与原子玩家交易。另有单机驿路商队。

在线市场是休闲社区经济：模拟运行在客户端，排行榜不保证竞技公平。服务器防止接口层面的重复结算和版本覆盖，但不证明客户端生产数据真实。没有注入示例玩家或假交易。

## 操作

| 操作 | 效果 |
|---|---|
| 点击建筑卡，再点地图 | 放置；显示占地与有效性 |
| 选择道路后拖动 | 连续铺路，松手结算实际有效路段 |
| 点击已有建筑 | 固定详情、查看需求、迁移或拆除 |
| 拖动地图 / 触屏单指拖动 | 平移 |
| 滚轮 / 双指捏合 / `+`、`−` | 缩放 |
| 右键 / `Esc` | 取消工具或选择 |
| `空格` / `1`、`2`、`4` | 暂停或改变模拟速度 |
| `H` / 小地图 | 回到城市或跳转疆域 |
| `B` / `I` / `N` | 建造栏 / 库存 / 昼夜模式 |
| `Ctrl+S` / `⌘S` | 保存当前城市 |
| `?` | 城建指南 |

起步建议：先给住宅供水，增加两座住宅。生产建筑和服务设施都需要持续连通主路；本版不保留旧骨架中“派工后断路仍服务”的漏洞。早期商铺需同类隔路成对，后期中央集市整合五种食物配送。建筑详情会列出实际缺口。

## 美术资产

资产由图像生成工具为本项目原创制作，随后进行透明图裁切、统一锚点、WebP 转码及动画图集合成。

- 5 组文明主体建筑，共 80 张独立图像。
- 16 张共用市政与产业辅助建筑；16 张自然地表与环境图像。
- 16 张地标与扩展建筑，其中 5 组文明专属建筑与终极奇观分别绘制。
- 16 帧施工 / 升级脚手架图像，并提供规范动画图集。
- 一张完整绘制的五文明河谷全景。
- 夜景使用运行时光照、精灵透明蒙版和局部灯点；运行时另绘水流、烟、旗帜、工人、吊机与行人。

共 144 张透明精灵。资源映射、锚点、来源和生成提示词见 [assets/manifest.json](assets/manifest.json)、[assets/sprites.json](assets/sprites.json) 与 [assets/generation-record.json](assets/generation-record.json)。

复用范围明确：普通住宅 10 个逻辑等级使用 3 档美术形态；部分辅助建筑跨文明共用；施工采用阶段图集叠加建筑轮廓和升级旧楼，并非每栋建筑、每个等级均有独立手绘序列。这个版本不能据此被称为已完成原作体量的全部内容。

## 验证

```bash
npm test
npm run build
npm run test:browser
```

浏览器测试首次运行需 `npx playwright install chromium`；若系统已有 Chromium，可设置 `CHROMIUM_PATH`。测试自动启动独立本地服务器并使用临时数据库，不影响玩家账号。

机制测试包括完全自然资源预算的六章通关，不通过添加资源绕过经济：固定测试路线第 669 回合奇观落成，人口 616。此路线证明可达性，不代表所有玩家的完成时长。可将 [examples/completed-city.json](examples/completed-city.json) 从城市档案导入，检查发展的城市；范例不是在线玩家。

HTTP 测试覆盖账号、权限、输入校验、版本冲突、交易并发、幂等、跨实例限流、持久化、Vercel 路由和生产缺库。PostgreSQL 复验必须使用独立一次性测试库，见部署文档。

浏览器测试覆盖真实按钮建造、两账号交易、异步收款合并、访客只读与回城、读档元数据、网络丢响应重试、成交后的列表刷新失败、手机布局及昼夜切换。最终画面与性能记录见 [VALIDATION.md](VALIDATION.md)。

## 代码结构

```text
index.html / style.css       游戏界面与统一视觉
js/data.js                  建筑、需求、章节与数值
js/civilizations.js         文明与经济差异
js/simulation.js            状态、地图、经济、建设、迁移与存档恢复
js/assets.js                原创精灵加载与映射
js/renderer.js              等距渲染、照明、动画、视图与缓存
js/ui.js / js/input.js      HUD、档案、鼠标与触摸操作
js/online.js / online.css   账号、云存、参观、排行与交易界面
server/                    HTTP、校验、持久化、Vercel适配及构建
api/index.js               Vercel函数入口
assets/                    原始图集、切片、动画、全景和来源清单
tests/                     模拟、HTTP和浏览器验证
examples/                  自然预算通关范例存档
```

本次明确选择的联网范围不含实时共同建城或实时战争。生产发布、真实移动设备性能及长期多人平衡仍须在最终环境验收；未完成这些验证前，不宣称已经达到或超越商业原版的总体品质。
