# 模拟帝国 · MVP 复刻

一个单机网页版《模拟帝国》(Sim Empire) 核心玩法复刻。纯前端，无依赖，双击 `index.html` 即可游玩。

---

## 快速开始

直接打开 `index.html`。或起一个本地服务器：

```bash
cd D:\me\project\citys
python -m http.server 8124
```

然后访问 `http://localhost:8124/`。

---

## 这是一个什么游戏

《模拟帝国》是 TKG Inc.（北京真知新游）2019 年发行的**等距视角古代文明城建游戏**，属《凯撒大帝 3》《法老》一脉的"Impressions 式"城市建造，而非《模拟城市》式划区。

本 MVP 复刻的是它真正有辨识度的机制，而不是通用的"造房子产资源"：

| 原作机制 | MVP 实现 |
|---|---|
| 等距网格城市，地图边缘有主路（路牌） | ✅ 右上角主路 |
| 道路连通：建筑首次派人需连路 | ✅ |
| **断路**：派人后拆路，建筑继续运作 | ✅ 仅非工业/农业可断路 |
| **商铺同种两座、隔路相对**才覆盖住宅 | ✅ |
| 住宅逐级累加需求（水→粮店+木材→菜店+粘土→…） | ✅ 10 级需求链 |
| 服务设施半径覆盖 | ✅ 悬停可见范围 |
| 全局劳动力池，设施占工 | ✅ |
| 声望决定移民速度 | ✅ 6 档声望 |
| 工业污染 vs 住宅美化（分区规划） | ✅ |
| 二级加工链（粘土→砖/陶器、粮→面包、水果→酒） | ✅ |
| 章节任务推进 + 奇观终局 | ✅ 6 章 |

未实现（单机 MVP 范围外）：多文明换皮、多人/联盟、世界地图资源点争夺、完整战斗系统、玩家交易市场、内购。

## 游戏规则

### 地图与道路

- 地图 20×20，**上边与右边是主路**（金色），移民由右上角的路牌进入。
- 所有建筑**第一次派人**时必须通过道路连到主路。
- **断路技巧**：建筑派满工人后，可以把道路拆掉，它仍继续运作。只有工业/农业建筑不能永久断路（原料耗尽停工后需要重新连路）。
- 用道路把建筑连成网络 —— 道路网本身必须与主路连通（BFS 判定）。

### 住宅与需求

住宅从 1 级升到 10 级，每升一级**累加**一项新需求：

| 等级 | 新增需求 | 人口 | 税收 |
|---|---|---|---|
| 1 | 道路 | 6 | 6 |
| 2 | 饮用水（水井） | 10 | 12 |
| 3 | 粮店 + 木材 | 16 | 22 |
| 4 | 菜店 + 粘土 | 24 | 38 |
| 5 | 水果摊 + 石料 | 32 | 60 |
| 6 | 鱼店 | 42 | 92 |
| 7 | 肉铺 + 神庙 | 52 | 140 |
| 8 | 陶器 + 学堂 | 64 | 200 |
| 9 | 酒水 | 78 | 280 |
| 10 | 布匹 + 戏台 | 96 | 400 |

- 升级还需要：住宅**住满 90%** 并稳定 12 回合。
- 需求断供 20 回合会**降级**。
- 住宅所在位置**净美化为负**（污染 > 美化）时无法升级 —— 这是分区规划的压力来源。

### 商铺成对机制（核心）

商铺**必须同种两座**，位于同一行或同一列，中间隔着一条**街道走廊**（1~5 格，中间不能有别的建筑），才能辐射覆盖住宅（半径 5）。

- 单座商铺不生效。
- 派人之后拆掉中间的路，配对关系**仍然保留**（断路技巧的一部分）。
- 界面会显示「已与对面同种商铺配对」或「需要另一座同种商铺隔路相对」。

### 断路（road disconnect）

- 建筑**派人时**必须连到主路；**派人之后**拆掉道路，它继续运作（旁边留一格断头路即可）。
- 可断路：商铺、市政（水井/值更房等）、仓储、文化、美化、奇观。
- **不可断路**：工业与农业建筑 —— 断路后立刻停止产出。

### 劳动力

- 人口即劳动力池。每座建筑占用固定工人数（农场 3、商铺 2、水井 2…）。
- 工人不足时，低优先级建筑停摆（工业/农业优先，商业/军事靠后）。
- 用鼠标悬停建筑可看到「缺工/未连路」状态。

### 声望

声望决定**移民迁入速度**：

| 声望 | 移民倍率 |
|---|---|
| 愤怒 | ×0.15 |
| 失望 | ×0.4 |
| 一般 | ×1.0 |
| 喜欢 | ×1.5 |
| 喜爱 | ×2.0 |
| 崇敬 | ×2.6 |

声望受：国库金币、缺工建筑数、失业率、粮食储备、住宅需求满足度、安全覆盖影响。

### 污染与美化

- 工业建筑（伐木场、采石场、粘土矿、砖窑、陶器坊、磨坊、织坊、酒坊、兵营）向周围 **size+1 格** 扩散污染。
- 美化建筑抵消污染：树（半径 1）、石碑（半径 2）、花园（半径 3）、水井（半径 2）。
- 住宅所在格 **美化 − 污染 < 0** 时不能升级。

### 章节

| 章节 | 目标 |
|---|---|
| 一 · 立足 | 建水井、住宅升到 2 级、住宅总数 4 座、人口 30 |
| 二 · 集市 | 一对粮店、值更房、采石场、3 级住宅、人口 70 |
| 三 · 百工 | 粘土矿、砖窑、一对菜店、2 座 5 级住宅、人口 160 |
| 四 · 城邦 | 陶器坊、一对水果摊、8 级住宅、人口 320、税收 3000 |
| 五 · 富庶 | 一对鱼店、一对肉铺、2 座 10 级住宅、声望「喜爱」 |
| 六 · 奇观 | 建成 3×3 奇观 |

> 注意：人口上限由住宅数量 × 等级上限决定。第二章要求人口 70，而 4 座 3 级住宅上限正好是 64 —— 需要再建一座住宅才能达标。

## 数值说明

原作的建筑造价、工人数、半径等数据大多以**图片表格**形式存在，未能取得确切数值。本 MVP 的数值是为让机制成立而**自行设计**的，目标是节奏合理、反馈清晰，而非还原原作数值。

## 已知限制

- 单一文明（波斯风格），未做四文明换皮。
- 无战斗系统；兵营仅为占位。
- 无存档槽位，只有单个自动存档（localStorage）。
- 无音效。
- 服务半径、造价、工人数等数值为自行设计（见上节）。

## 已验证的机制

以下都在浏览器里实测通过（`preview_eval` 驱动）：

- 点选精度：100 个采样格，落点误差 0。
- 断路：商铺断路后 `connectedToMain` 仍为真、配对保留；伐木场断路后立刻 `linked=false`、产量归零。
- 成对商铺：单座 `shopPairCount=0`；隔一格路相对后 `=1`。
- 需求链：1 级 → 2 级（水井）→ 3 级（粮店+木材）→ 4 级（菜店+粘土），逐级累加。
- 二级加工：粘土矿 → 砖窑，粘土被消耗、砖产出。
- 章节推进：第一章 → 第二章 → 第三章，任务逐条触发。
- 税收：住宅满足当前等级需求且入住 ≥60% 时按周期产生金币。
